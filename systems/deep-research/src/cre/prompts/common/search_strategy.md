Search is downstream of argument formation. Before every search, name the existing argument, clash or proof obligation that the result could change. Never search merely because a phrase is related to the proposition.

Choose one of two modes:

ARGUMENT DISCOVERY (normally first)
- Exact-motion archaeology: search the proposition verbatim plus terms such as debate, round, transcript, speech, rebuttal, judge, review or the equivalents in the relevant language.
- Adjacent-motion transfer: look for a different proposition with the same burden, value conflict, mechanism, analogy or counterexample.
- Public-reasoning scan: sample forums, essays, comments and personal accounts to discover recurring intuitions, objections and language. Popularity is not truth; the value is argumentative discovery.
- Concept/example search: locate philosophical distinctions, historical cases, literature, news events or thought experiments that make a warrant clearer.

FACT VERIFICATION (only for a named factual need)
- Trace an important empirical claim to an appropriate original or authoritative source.
- Check causal mechanism, scale, population, counterexamples, alternative explanations and boundary conditions.
- Stop when the particular factual premise is adequately supported or defeated. Do not continue collecting papers for prestige.

Operate in small batches of purpose, not endless serial wandering. A result is valuable only if it adds a new argument family, improves a warrant, supplies a useful example, reveals an attack, or resolves a factual need. If it does none of these, discard it. After two materially different failed queries for the same need, change the argument or park the branch.

ACCESS ROUTING
- Prefer a documented structured API or stable public repository when it can answer the same question as a brittle page. This reduces transport failure; it does not make the claim true by itself.
- For concepts, public events and background cases, use Wikimedia/API-backed pages as a readable starting map, then trace any decisive fact when necessary.
- For biomedical claims, prefer PubMed/NCBI records; for scholarly metadata, prefer Crossref or another open index. Metadata proves publication identity, not the paper's conclusion.
- For public statistics, prefer the relevant official data API or downloadable table (for example World Bank, UN, OECD, national statistics) only after naming the exact indicator needed.
- Debate videos, forums and essays remain valid argument-discovery material. A video landing page is not a transcript and must never count as a deep read. Use its title/snippet as a lead, seek a transcript, subtitle export or alternate reconstruction once, then move on.

Search-result snippets are leads. For argument discovery, a transcript, forum post or review may be read for the reasoning it contains without being treated as authoritative evidence. For factual verification, inspect the source appropriate to the claim.

Never read the same source twice merely with a different purpose. Its inspected text is already preserved in the source shortlist; extract every useful point in one synthesis turn, then record, attach, or discard it.
