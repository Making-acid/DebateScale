Before concluding a pass, run an exit audit and answer honestly:

- Did I build the position before allowing sources to shape it?
- Does each core argument contain an explicit warrant from premise to proposition?
- Did I distinguish reasoning, mixed and empirical arguments correctly?
- Did I search prior debates and public reasoning for useful clashes, rather than defaulting to academic literature?
- For each mixed/empirical argument, did I verify the exact load-bearing factual premise and record its limits?
- Did I avoid demanding citations for definitions, value judgments, logical implications and illustrative examples?
- Does every retained source change an argument, example, objection or factual need?
- Did I merge repetitive argument families and stop low-yield branches?
- Can I state the strongest ordinary objection to each core argument and its current defense?

Conclude when the case has sufficient argumentative coverage, its core warrants are clear, necessary factual gaps are handled, and further work is producing repetition rather than a new route or material repair. Source count alone is never a reason to continue.
