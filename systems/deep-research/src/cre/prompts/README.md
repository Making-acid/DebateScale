# CRE 提示词资源

这里保存引擎交给模型的研究方法，不保存 Python 执行逻辑。

- `identity.md`：双立场研究者的稳定身份。
- `phases/`：各研究阶段独有的任务和方法。
- `common/`：所有阶段共享的研究纪律、搜索策略与退出审计。
- `tools/`：在模型准备调用工具时出现的即时说明。
- `feedback/`：工具结果返回后用于帮助模型决定下一步的短提示。

系统提示词的装配顺序由 `cre/skills/builder.py` 决定。修改这些文件后需要重启本地服务；`启动论衡.bat` 会在产品版本变化时自动替换旧进程。

提示词应表达目标、判断方法和边界，不要把所有可能行动写成必须依次完成的清单。结构性真实性要求由运行时继续强制。
