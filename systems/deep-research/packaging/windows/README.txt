DebateScale · 论衡 Windows 便携展示版
=====================================

一、启动
双击 DebateScale.exe。程序会在本机启动研究服务并自动打开浏览器。
若浏览器没有自动打开，请访问：http://127.0.0.1:8765/

二、首次使用
打开右上角“设置”，选择模型供应商，填写 API Key 和模型，然后测试连接。
本安装包不包含发布者的 API Key、模型设置或研究记录。

三、数据位置
设置、研究历史和生成结果保存在本文件夹的 data 目录中。若要把程序交给
其他人，请先删除 data 目录，以免把自己的 API Key 或研究记录一起交付。

四、关闭
关闭浏览器不会自动停止后台服务。需要彻底退出时，请双击 shutdown.bat。

五、网络与安全提示
首次启动时 Windows 可能询问是否允许网络访问。论衡只监听本机地址
127.0.0.1；联网用于调用用户自行配置的模型 API、搜索公开网页，以及按需
下载语音识别模型。不要把来源不明的 API Key 填入本程序。
