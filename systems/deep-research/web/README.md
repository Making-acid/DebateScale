# 论衡双边深度研究工作台

这是 Continuous Research Engine 的本地交付前端。它会为每个新辩题创建独立研究，调用两套隔离上下文中的立场模型，联网搜索与深读来源，形成双方立论、证据链、基础驳论与修复结果。首页优先展示当前有效成果；旧版本、内部工单和各轮过程放在“推演历史”中。

## 启动

最简单的方式是双击项目上一级目录中的 `启动论衡.bat`。也可以在 PowerShell 中运行：

```powershell
.\start_web.ps1
```

也可以在 `continuous_research_engine` 目录直接运行 `python web/server.py`。

浏览器会自动打开 `http://127.0.0.1:8765`。

## 研究方式

- 默认“深度研究”要求每方至少发现 40 个来源、深读并登记 20 条论证证据、形成 4 个完整论点和 3 个完整驳论；双方首轮并行运行。
- “标准研究”适合较轻的试跑：每方至少 24 个来源、深读 12 条证据、3 个完整论点和 2 个完整驳论。
- 搜索使用无需额外密钥的公开网页入口，并在一个入口失效时自动切换备用入口；重要主张仍要求模型打开原文，而不是只看摘要。
- 结果自动保存在 `web/.local/researches`，可从左侧列表再次打开；导出支持可直接阅读的 PDF 和独立 HTML。
- 左侧历史列表支持逐条删除和一键清理失败记录；删除内容会先移入 `web/.local/trash`，不会立即永久销毁，正在运行的任务则不会提供删除入口。

## 模型 API 设置

侧边栏的“模型 API”页面可选择内置供应商或通用兼容接口：

- 第一方直连包括 OpenAI、DeepSeek、Anthropic Claude、Google Gemini、Mistral AI、MiniMax，以及已有的智谱、阿里云百炼、火山方舟与 xAI 等官方入口；无需为了使用某家公司自己的 key 而选择聚合站。
- API 基础地址与密钥。
- A 方和 B 方的独立模型 ID。
- 单次请求超时时间。
- A 方和 B 方可以使用相同或不同模型。
- 支持 OpenAI Responses、OpenAI Chat Completions、Anthropic Messages 与 OpenCode Go 分模型路由。
- 保存设置后会自动通过供应商的模型列表接口读取完整目录，并同时更新 A、B 两方的模型下拉栏；也可随时手动刷新。该检查不会产生模型生成费用。
- 模型生成请求遇到临时限流或连接中断时会自动退避重试；OpenCode Go 的双边请求还会自动错峰，降低瞬时限流概率。

配置保存在本机 `web/.local/model_config.json`。浏览器读取设置时不会取得密钥原文，只能看到是否已配置以及末四位提示。
