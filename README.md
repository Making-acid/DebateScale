# DebateScale · 论衡

DebateScale 是一个容纳多个独立辩论研究系统和可选平台接入的工具集合。它帮助辩手与研究者理解辩题、建立双方论证、检查推理，并把研究成果整理成可以直接阅读和备赛的报告。

> 当前处于早期开发阶段。每个系统都以完整、可独立运行的交付包为目标；现有 Web 工作台是深度研究系统的标准本地启动方式，但不是唯一接入形式。

## 当前组件

### Deep Research System

位于 [`systems/deep-research`](systems/deep-research)，负责在接到新辩题后展开双方研究：

- 两个模型分别坚持正、反立场；
- 先建立论证，再按需搜索材料；
- 检查事实错误和推理缺口；
- 修补双方论证并整理成易读报告；
- 支持检查点恢复、过程观察及 PDF 导出。

Windows 用户可以双击根目录的 `启动论衡.bat` 启动当前工作台。

## 仓库布局

```text
DebateScale/
├─ systems/              # 完整、自洽、可单独交付的研究系统
│  └─ deep-research/     # 当前深度研究系统
├─ integrations/         # 平台接入说明和极薄适配层
├─ docs/                 # 产品与架构文档
└─ 启动论衡.bat          # 当前 Windows 启动入口
```

## 架构原则

各系统不是同一个核心的不同模式，而是并列的独立产品单元。系统之间不共享提示词、状态模型、研究策略、工具实现或运行资产，也不得直接导入彼此的内部代码。必要的重复优先于隐式耦合。

平台接入只能依赖某个系统很小的公开表面。仓库本身也应当可以作为发行渠道：无论目标平台是否拥有插件市场，使用者都应当能够从对应接入目录直接找到最短的连接方式。接入层不得把独立系统重新耦合成一个共同运行时。

完整说明见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。

## 安全提示

API Key、模型配置、研究历史、日志和生成报告只保存在本地，均被版本控制规则排除。提交代码前仍应检查暂存内容，避免上传任何凭据或未脱敏材料。
