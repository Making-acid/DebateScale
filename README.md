# DebateScale · 论衡

DebateScale 是一个由多个独立辩论思考引擎和可选接入插件组成的工具集合。它帮助辩手与研究者理解辩题、建立双方论证、检查推理，并把研究成果整理成可以直接阅读和备赛的报告。

> 当前处于早期开发阶段。现有 Web 工作台主要用于验证引擎，并不代表最终产品形态。

## 当前组件

### Deep Research Engine

位于 [`engines/deep-research`](engines/deep-research)，负责在接到新辩题后展开双方研究：

- 两个模型分别坚持正、反立场；
- 先建立论证，再按需搜索材料；
- 检查事实错误和推理缺口；
- 修补双方论证并整理成易读报告；
- 支持检查点恢复、过程观察及 PDF 导出。

Windows 用户可以双击根目录的 `启动论衡.bat` 启动当前工作台。

## 仓库布局

```text
DebateScale/
├─ engines/              # 相互独立、可单独安装运行的引擎
│  └─ deep-research/     # 当前深度研究引擎
├─ plugins/              # ChatGPT、DSH、MCP 等外部接入
├─ docs/                 # 产品与架构文档
└─ 启动论衡.bat          # 当前 Windows 启动入口
```

## 最重要的架构原则

各引擎不是同一个核心的不同模式，而是并列的独立产品单元。引擎之间不共享提示词、状态模型、研究策略、工具实现或运行资产，也不得直接导入彼此的内部代码。必要的重复优先于隐式耦合。

插件只能依赖某个引擎明确公开的接口。一个插件可以适配多个引擎，但不得把引擎重新耦合成一个共同运行时。

完整说明见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。

## 安全提示

API Key、模型配置、研究历史、日志和生成报告只保存在本地，均被版本控制规则排除。提交代码前仍应检查暂存内容，避免上传任何凭据或未脱敏材料。
